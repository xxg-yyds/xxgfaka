了解小小怪卡密系统

同一服务器或内网

推荐 · 一键对接
  1. 在发卡网后台「系统设置 · 卡密系统对接」保持「允许一键对接」开启
  2. 在卡密系统「发卡网对接」页点击「检测本地发卡网」，通过标准发现接口 /.well-known/xxgkami-card-shop 扫描到本站
  3. 选择 XXG发卡网，点击「一键添加」，对接 ID 与密钥自动下发，设置页显示「卡密系统在线」

不同服务器

手动对接
  1. 在卡密系统中添加发卡网，对接地址填写发卡网设置页显示的「本站对接地址」
  2. 把卡密系统生成的对接 ID 与密钥填入发卡网，并填写卡密系统接口地址
  3. 点击「检测连接」；还可额外配置一个内网地址，公网不通时自动切换

    自动发货

    卡密展示在订单页一键复制，配置邮箱后同时发送到买家邮箱。

几分钟搭建自己的发卡网

前后端分离，后端单个 Jar 包运行，前端构建为静态文件交给 Nginx 托管。Linux 与 Windows 服务器均可部署。

JDK 21+ MySQL 8+ Redis 5+ Node.js 18+ Maven 3.8+
商城前台http://localhost:1506
管理后台http://localhost:1506/admin
后端接口http://localhost:1505/api
下载最新版 阅读部署文档 
# 1. 后端：修改 application.properties 中的数据库与 Redis 配置
cd backend
mvn spring-boot:run          # 监听 1505，首次启动自动建表

# 2. 前端：开发模式，/api 自动代理到 1505
cd vue
npm install
npm run dev                 # 打开 http://localhost:1506
# 后端打包并后台运行
cd backend && mvn -DskipTests package
nohup java -jar target/*.jar > faka.log 2>&1 &

# 前端构建，dist 目录交给 Nginx
cd vue && npm install && npm run build

# Nginx：静态文件 + /api 反向代理
location / { try_files $uri $uri/ /index.html; }
location /api/ { proxy_pass http://127.0.0.1:1505; }

发卡网常见问题

没有找到答案？欢迎到 GitHub 提交 Issue。

XXG发卡网是免费的吗？

是的。XXG发卡网的完整源码公开在 GitHub，可以免费下载并部署在自己的服务器上，没有按订单抽成，也没有功能限制。

如何搭建自己的发卡网？

准备一台安装了 JDK 21、MySQL 8 和 Redis 5 的服务器，下载发布包或源码，修改数据库配置后启动后端，再把前端构建产物交给 Nginx 托管。首次启动会自动建表并写入示例数据，几分钟就能上线。

必须搭配小小怪卡密系统使用吗？

不必须。XXG发卡网可以独立使用，在后台批量导入卡密（支持 TXT 文件，自动全局去重）即可开卖。搭配小小怪卡密系统后，卡密的生成、上架、售出与验证可以全程自动流转。

两套系统不在同一台服务器，还能对接吗？

可以。一键对接仅限本机或内网，跨服务器时在卡密系统中手动添加发卡网，再把对接 ID 与密钥填入发卡网设置页即可，还可以额外配置一个内网地址作为备用线路。

同一张卡密会不会卖给两个人？

不会。卡密分配与库存扣减在数据库事务中完成；来自卡密系统的卡密在发货前会先回传售出，卡密系统确认后才发货，已被他处使用的卡密会自动换成另一张。

订单退款后，卡密怎么处理？

退款时可以选择回收卡密并重新上架。手动导入的卡密直接回收；来自卡密系统的卡密会先撤销售出，回到卡密系统重新可售，买家已经使用过的卡密则保持已售。

现在支持哪些支付方式？

当前支持余额支付。支付宝、微信、USDT 真实支付通道正在开发中，默认开启的沙箱模式提供模拟扫码支付，便于演示和测试完整流程，正式运营前请在后台关闭沙箱模式。

不同规格的卡密能分别卖给不同商品吗？

可以。卡密系统的卡密按「应用 + 规格」自动分类，例如「我的软件 · 30天卡」，每个分类可以配置给一个商品，一个商品也可以绑定多个分类。未配置的卡密进入卡密池，随时可以手动上架。

初始管理员账号在哪里设置？

在 application.properties 的 xxg.init.admin-username 与 xxg.init.admin-password 中配置，首次登录后台后请立即修改密码。
